# Useful Web Development & AI Design Resources

A curated collection of design component libraries, AI skills, prompt systems, and UI inspiration.

---

## 1. [Vengeance UI](https://www.vengenceui.com/)
* **Category:** React & Animation UI Library
* **Description:** A specialized collection of animated React components and next-generation UI interactions built for high-converting, modern landing pages.
* **Key Features:**
  * Animated React & Framer Motion components.
  * Ready-to-use micro-interactions, hero sections, and visual cards.
  * Modern design aesthetics optimized for SaaS and tech landings.

---

## 2. [Apple Design Skill (GitHub)](https://github.com/dickwu/apple-design-skill)
* **Category:** AI Agent Skill / UI & UX Reviewer
* **Description:** An open-source AI agent skill grounded in **Apple’s Human Interface Guidelines (HIG)** designed to review UI/UX code and designs.
* **Key Features:**
  * Context-aware design auditing for AI agents (Cursor, Claude Code, Antigravity, etc.).
  * Cross-platform support (SwiftUI, UIKit, React Native, Flutter, Electron, Web).
  * Evaluates layout, typography, interaction standards, and platform-native feeling.

---

## 3. [21st.dev](https://21st.dev/)
* **Category:** Component Marketplace & AI UI Registry
* **Description:** A massive directory of over 12,000+ hand-crafted React and Tailwind CSS components, templates, and shadcn/ui themes built by design engineers.
* **Key Features:**
  * One-command CLI installation directly into projects (`npx 21st@latest add`).
  * AI-agent friendly integration for automatic UI component retrieval.
  * Live interactive previews with customizable themes and copy-paste code.

---

## 4. [MotionSites AI](https://motionsites.ai/)
* **Category:** AI Website Prompts & 3D Web Design
* **Description:** A platform featuring premium website prompts tailored for AI web builders (Lovable, Bolt, Cursor, Claude).
* **Key Features:**
  * Copy-and-paste structured prompts optimized for generating 3D and animated websites.
  * Tailored for modern AI web generation tools.
  * Enables fast prototyping of interactive 3D hero sections and dynamic layouts.
